# Community skills

Skills shared by other users land here.

- Install one from anywhere: `/skill install <github-or-raw-url>` in chat (you review the full
  text before it is written — a skill is instructions your agent will follow).
- Share yours: open a PR adding `skills/<category>/<name>/SKILL.md` to `templates/workspace/skills`
  in the kit repo — merged skills reach every install on their next `xdc-agent update`.
